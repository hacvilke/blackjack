# Blackjack — Velvet Nines ♠

A fully-animated casino blackjack table (6 decks, S17, 3:2, double, split,
chips, sounds) — **offline-first**, zero backend, zero gambling. Works as a
web app, an Android APK, and an iOS app.

## Get it

- **Android:** `Blackjack-v1.0.0.apk` (CI artifact). Sideload: Settings → allow
  install from that one browser/files app → install. Play Protect may note
  "unknown app" — normal for anything outside Play. The app requests **no
  permissions at all** (no internet — the game ships inside).
- **iOS, warning-free (recommended):** open the game URL in Safari → Share →
  **Add to Home Screen**. Fullscreen app, zero Apple warnings, nothing to sign.
- **iOS, real app:** download `Blackjack-unsigned.ipa` (CI artifact) and sideload
  with **AltStore** or **Sideloadly** (free, signs with your own Apple ID; re-sign
  every 7 days). First launch: Settings → General → VPN & Device Management →
  trust your certificate. A warning-free *installed* app requires Apple's
  $99 developer program (TestFlight/App Store) — physics of the walled garden.
